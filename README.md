# C--calculator-

A simple calculator program written in C.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- Handles invalid operators 

## 2. Even Odd Checker
A simple program to check whether a number is even or odd.


## How to Run

1. Open the C program in any C compiler.
2. Compile and run the program.
3. Enter the required input.
4. View the output.
